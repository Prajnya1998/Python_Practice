## Project 1: Global Superstore Analysis

### Technologies Used

* Python
* Pandas
* SAS Studio
* GitHub

### Dataset

* Global_Superstore_100.csv
* Global_Superstore(CSV).csv

### Objective

Analyze Global Superstore sales data using Python and Pandas, create a technology-specific dataset, and import the results into SAS Studio for further analysis.

### Tasks Performed

1. Loaded CSV file using Pandas
2. Explored dataset structure
3. Checked rows and columns
4. Reviewed column names and data types
5. Identified missing values
6. Filtered Technology category records
7. Exported filtered data to technology_sales.csv
8. Imported technology_sales.csv into SAS Studio
9. Performed SAS analysis using PROC IMPORT and PROC SQL
